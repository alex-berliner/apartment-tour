# Apartment Tour

A 360° walkthrough of a one-bedroom apartment, rendered from a Blender model (Cycles path tracing), in several versions:

- **As furnished**, evening and daytime
- **Recommended paint**, evening and daytime
- **Style studies:** Collected Mid-Century, Quiet Library and Edited Heritage

Open the site, drag to look around, click the floor rings to move between spots, and use **Version** to switch configurations. You stay at the same spot and keep looking the same way.

Links can point at a version and spot: `?v=style_library&at=office_1`.

Evening versions use the lighting levels from the project's lighting optimiser. Daytime versions are a clear mid-October noon sky.
